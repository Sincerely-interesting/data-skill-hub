# 视频分镜头脚本标准格式模板

> **适用场景**: 电商短视频内容策划、广告片制作、产品展示视频
>
> **核心目标**: 将创意概念转化为可执行、可量化、可协作的标准化文档
>
> **参考标准**: 影视工业级分镜头规范 + 电商快节奏叙事优化

---

##  基础信息区

```yaml
项目名称: _______________________
客户/品牌: _____________________
视频时长: _____秒 (建议15s-60s)
制作日期: YYYY-MM-DD
版本号: V1.0 (最终版)

核心传达信息:
  - 主卖点1: _________________
  - 主卖点2: _________________
  - 情感基调: _________________

目标平台:
  - [ ] 抖音 (9:16 竖屏, <30s)
  - [ ] 小红书 (3:4 或 1:1, <3min)
  - [ ] 得物App (1:1 或 16:9)
  - [ ] 淘宝主图视频 (1:1, <30s)
  - [ ] 微信朋友圈 (1:1, <15s)

音乐风格:
  - 类型: [电子/轻音乐/Hip-Hop/ASMR/原声]
  - 节奏: [快(>120BPM)/中(90-120BPM)/慢(<90BPM)]
  - 情绪: [激昂/轻松/神秘/温馨]
```

##  分镜头脚本正文

### 场景编号规则

```
格式: 场景{序号}: {场景名称} {场景类型}

示例:
  场景1: 朦胧暖光预热场景 (氛围铺垫)
  场景2: 复古书房展陈场景 (产品展示)
  场景3: 休闲落座穿搭场景 (使用演示)
  ...
```

### 单个场景完整结构

每个场景必须包含以下 **6个核心要素**:

#### 要素1⃣ 故事脚本（Story Script）

**目的**: 定义"这一场要讲什么"

```
字段说明:
  - 叙事目标: 本场在整体故事线中的作用
  - 核心内容: 具体发生了什么
  - 情绪转换: 从什么情绪转到什么情绪
  - 信息密度: 观众应接收到的关键信息点

填写要求:
   用2-4句话描述清楚
   避免技术术语，用画面语言思考
   明确本场与上一场的衔接关系
```

**示例**:
```markdown
### 故事脚本：
以朦胧柔暖的光影开场，弱化环境细节，先勾起观众的好奇心，逐步带出鬼冢虎复古休闲鞋，铺垫整体复古雅致的广告氛围。

**解析**:
- 叙事目标: 开场吸引注意力 + 建立调性
- 核心内容: 光影过渡 → 产品露出
- 情绪转换: 好奇 → 期待
- 信息点: "这是一支有质感的广告"
```

#### 要素2⃣ 运镜技巧（Cinematography）

**目的**: 定义"怎么拍才好看"

```
字段说明:
  - 镜头类型: [固定/推拉/摇移/跟拍/升降/旋转]
  - 运镜方式: 详细描述运动轨迹
  - 景别变化: [全景→中景→特写] 的变化逻辑
  - 焦点控制: 焦点从哪转移到哪
  - 特殊效果: [慢动作/加速/定格/模糊转清晰]

专业术语对照表:
  ┌─────────────┬────────────────────────────────────────┐
  │ 专业术语     │ 含义 & 使用场景                        │
  ├─────────────┼────────────────────────────────────────┤
  │ 缓慢推镜     │ 镜头向前推进，用于聚焦主体或制造压迫感   │
  │ 缓慢拉镜     │ 镜头向后拉开，用于展示全貌或释放情绪     │
  │ 微距推镜     │ 特写+推进，强调材质细节                 │
  │ 固定全景     │ 镜头不动，展示环境和人物关系             │
  │ 固定中景     │ 聚焦人物上半身或商品主体                 │
  │ 跟拍         │ 跟随运动主体，增强动感                   │
  │ 摇镜         │ 镜头水平转动，扫描场景                   │
  └─────────────┴────────────────────────────────────────┘
```

**示例**:
```markdown
### 运镜技巧：
缓慢推镜，从弥散的光晕中缓缓聚焦到鞋身局部，自然带出产品主体。

**技术参数建议**:
- 镜头运动速度: 3秒完成推镜 (营造优雅感)
- 起始焦点: 光晕/环境虚化
- 终止焦点: 鞋身纹理清晰
- 景深变化: f/2.8 → f/5.6 (由浅入深)
- 运动曲线: Ease-in-out (缓入缓出，非匀速)
```

#### 要素3⃣ 人物动作与特征（Character Action）

**目的**: 定义"人物在做什么、呈现什么状态"

```
字段说明:
  - 出镜状态: [全身/半身/局部/不出镜]
  - 动作描述: 具体的肢体语言和动作细节
  - 表情管理: 面部表情或身体姿态传递的情绪
  - 服装道具: 穿搭细节和手持物品
  - 与商品关系: [佩戴/持握/展示/互动/无视]

动作设计原则:
   自然不做作 (避免摆拍感)
   功能导向 (动作服务于卖点展示)
   符合人设 (与目标用户画像一致)
   有记忆点 (独特的小动作或习惯)
```

**示例**:
```markdown
### 人物动作与特征：
仅露出穿着复古休闲鞋的脚部局部，姿态自然静置，不露面部，整体氛围低调雅致。

**详细分解**:
- 出镜状态: 仅脚部 (制造神秘感)
- 动作描述: 双脚自然交叠，轻微晃动暗示舒适度
- 表情管理: N/A (不露面部)
-服装道具: 浅卡其色中筒棉袜 (增加生活气息)
- 与商品关系: 自然穿着 (非刻意展示)

 注意事项:
- 脚部皮肤需做好保养 (避免干燥起皮)
- 袜子颜色需与鞋款配色协调
- 姿态避免过于僵硬 (可让模特先放松聊天再抓拍)
```

#### 要素4⃣ 台词/旁白/字幕（Audio & Text）

**目的**: 定义"听觉层面传达什么信息"

```
字段说明:
  - 文字内容: 实际的台词/旁白文案
  - 语音风格: [男声/女声/童声/合成音] + [语气]
  - 字幕样式: [位置/字体/颜色/动画效果]
  - 音效配合: [环境音/特殊音效/静音处理]
  - 时间节点: 文字出现的精确时间点

文案撰写原则:
   口语化 (避免书面语)
   短句为主 (每句<12字为佳)
   有节奏感 (配合画面切换)
   包含关键词 (利于搜索和标签)
```

**示例**:
```markdown
### 台词/旁白：
(无台词，纯视觉叙事)

**替代方案A (如需配音)**:
旁白: "有些经典，无需多言。" (第3秒出现)
语音: 温暖女声，语速缓慢 (每秒3字)
字幕: 屏幕下方居中，白色细体字，淡入淡出

**替代方案B (文字版)**:
字幕叠加: "TIMELESS DESIGN" (第5秒出现，停留2秒)
字体: Helvetica Neue Light, 48pt, 白色
特效: 从透明渐变到100% opacity，保持1.5秒后渐隐
```

#### 要素5⃣ 时长与节奏（Timing & Pacing）

**目的**: 定义"这场戏持续多久、节奏如何"

```
字段说明:
  - 持续时长: ___秒 (精确到0.5秒)
  - 节奏类型: [舒缓/紧凑/跳跃/停顿]
  - 剪辑点建议: 在哪里切换到下一场
  - 信息密度: [高(信息量大)/低(留白多)]

时长分配原则 (以30s视频为例):
  ├─ 开场钩子 (0-3s): 10% - 抓住注意力
  ├─ 问题/痛点 (3-8s): 17% - 建立共鸣
  ├─ 解决方案 (8-20s): 40% - 核心展示
  ├─ 证据支撑 (20-26s): 20% - 建立信任
  └─ 行动召唤 (26-30s): 13% - 促进转化
```

**示例**:
```markdown
### 时长与节奏：
- 持续时长: 4秒
- 节奏类型: 舒缓 (建立期待感)
- 剪辑点: 第4秒末尾，鞋身完全清晰时切场
- 信息密度: 低 (主要作用是氛围铺垫，非信息输出)

**时间轴可视化**:
00:00 ──── 01:00 ──── 02:00 ──── 03:00 ──── 04:00
|█████████|█████████|█████████|█████████|
光晕弥漫    渐现轮廓    鞋身清晰    定格展示    ← 切场
```

#### 要素6⃣ 灯光与布光（Lighting Setup）

**目的**: 定义"光线如何塑造氛围和质感"

```
字段说明:
  - 主光源: [方向/色温/强度/灯具类型]
  - 辅助光: [补光/轮廓光/背景光的设置]
  - 光比: 主光与辅光的亮度对比 (如 2:1, 4:1)
  - 色彩氛围: 整体色调倾向 (暖调/冷调/中性)
  - 特殊效果: [逆光/轮廓光/投影/光斑]

常用布光方案:
  ┌──────────┬─────────────────────────────────────┐
  │ 方案      │ 适用场景 & 效果                      │
  ├──────────┼─────────────────────────────────────┤
  │ 45°侧逆光 │ 强调材质纹理 (皮革、翻毛皮)          │
  │ 顶光      │ 模拟自然光，适合户外场景复刻          │
  │ 伦勃朗光  │ 戏剧感强，适合高端奢侈品              │
  │ 大面积柔光│ 干净清透，适合美妆、护肤品类          │
  │ 轮廓光    │ 勾勒边缘，分离主体与背景              │
  └──────────┴─────────────────────────────────────┘
```

**示例**:
```markdown
### 灯光布光：
- 主光源: 左侧45°侧逆光，2700K暖色调，柔光箱柔化
- 辅助光: 右侧反光板补光 (光比 3:1)
- 色彩氛围: 整体偏暖 (模拟黄昏书房灯光)
- 特殊效果: 背景书架添加暖黄色LED灯带 (增加层次)

**器材清单**:
- 主灯: Godox SL150W II × 1 (配90cm八角柔光箱)
- 补光: A4银色反光板 × 1
- 氛围灯: LED灯带 2米 (色温可调)
- 参考曝光: ISO 400, f/2.8, 1/60s
```

##  完整案例：鬼冢虎复古休闲鞋广告（5场景）

## 场景1：朦胧暖光预热场景

### 故事脚本：
以朦胧柔暖的光影开场，弱化环境细节，先勾起观众的好奇心，逐步带出鬼冢虎复古休闲鞋，铺垫整体复古雅致的广告氛围。

**叙事功能**: 开场吸引注意力 + 建立品牌调性  
**情绪曲线**: 好奇 (0%) → 期待 (100%)

### 运镜技巧：
缓慢推镜，从弥散的光晕中缓缓聚焦到鞋身局部，自然带出产品主体。

**技术参数**:
- 镜头: 50mm f/1.8 (全画幅等效)
- 运动: 缓慢直线推进，历时3.5秒
- 焦点变化: 起始焦距∞ → 终止焦距0.8m
- 景深: f/2.0 (起始) → f/4.0 (终止)
- 运动曲线: 自定义Ease-out (前快后慢，突出产品时减速)

### 人物动作与特征：
仅露出穿着复古休闲鞋的脚部局部，姿态自然静置，不露面部，整体氛围低调雅致。

**动作指导**:
- 模特坐姿: 坐在高度45cm的矮凳上
- 脚部位置: 画面右下角三分之一处
- 姿态: 双脚自然分开30cm，脚尖微微外八字
- 动态: 极轻微的前后摇摆 (暗示穿着舒适)
- 服装: 浅卡其色棉袜 (袜筒高度8cm)

### 台词/旁白：
(本场景为纯视觉叙事，无台词)

**备选字幕方案**:
```
时间轴: 02:50 - 04:00
文字: "SINCE 1949" (品牌成立年份)
字体: Didot Bold, 36pt, #F5E6D3 (米白色)
位置: 画面左上角，距离边缘10%
动画: Opacity 0%→80%→0% (淡入淡出)
```

### 时长与节奏：
- **持续时间**: 4秒
- **节奏类型**: 舒缓悠扬 (BPM 60-70)
- **剪辑点**: 第4.0秒末尾 (鞋身纹路完全清晰时硬切)
- **下一场衔接**: 直接切入场景2的全景镜头 (形成"局部→全局"的视觉节奏)

### 灯光布光：
- **主光源**: 左上方45°侧逆光，色温2800K，功率60%
- **辅助光**: 右下方反光板 (填充阴影，光比2.5:1)
- **轮廓光**: 后方弱轮廓光 (分离脚部与暗背景)
- **色彩氛围**: 整体偏暖 (#D4A574 主色调)
- **特殊效果**: 空气中加入微量烟雾 (增强光束可见度)

**拍摄难点及解决方案**:
| 难点 | 解决方案 |
|------|---------|
| 推镜过程中失焦 | 使用跟焦器或预标记焦点位置 |
| 光晕过曝 | 使用ND滤镜减光2档 |
| 脚部肤色不均 | 提前2小时涂抹身体乳 |

## 场景2：复古书房展陈场景

### 故事脚本：
正式展示完整鞋款产品，将两双复古休闲鞋放置在书堆之上，传递出产品兼具复古质感与休闲格调的品牌调性，凸显雅致的穿搭氛围感。

**叙事功能**: 产品完整亮相 + 场景调性强化  
**情绪曲线**: 期待 → 认知 (清晰看到产品全貌)

### 运镜技巧：
先固定全景镜头展示书架整体，再缓慢推镜聚焦到鞋款展示区域，清晰呈现产品全貌。

**技术参数**:
- 镜头: 24-70mm f/2.8 (变焦镜头)
- 起始焦段: 24mm (广角展示环境)
- 终止焦段: 50mm (聚焦产品)
- 运动: 先静止2秒 → 推镜2秒 → 再静止1.5秒
- 机位高度: 与桌面平齐 (俯视15°角)

### 人物动作与特征：
无人物出镜，仅展示摆放整齐的两双复古休闲鞋，静置展示产品完整外观。

**产品陈列规范**:
- 陈列数量: 2双 (一双米白，一双深棕)
- 摆放角度: 左侧45°侧面朝向镜头，右侧正面对镜头
- 高度差: 使用书籍垫高右侧鞋款 (形成错落感)
- 配合道具:
  - 左侧: 堆叠的旧书 (3-4本，书脊外露)
  - 右侧: 复古眼镜 + 钢笔 + 摆脱笔记本
  - 背景: 实木书架 (深胡桃木色)

### 台词/旁白：
(本场景仍为视觉主导，可选择性添加)

**推荐旁白** (女声，温暖知性):
```
时间轴: 01:50 - 04:50
文案: "经典，从不被时间定义。"
语速: 每秒2.5字 (从容不迫)
背景音乐: 音量降低至40% (突出人声)
```

**字幕版本**:
```
时间轴: 03:00 - 05:00
大标题: "CLASSIC REDEFINED"
副标题: "复古 · 重新定义"
字体: 大标题用 Playfair Display Bold
       副标题用 Noto Sans SC Light
```

### 时长与节奏：
- **持续时间**: 5.5秒 (全场最长，给观众足够时间观察产品)
- **节奏类型**: 平稳舒展 (BPM 70-80)
- **剪辑点**: 第5.5秒末尾 (观众已看清所有细节后切场)
- **下一场衔接**: 切换到场景3的中景镜头 (从"物"转向"人")

### 灯光布光：
- **主光源**: 正前方柔光箱 (均匀照亮产品，无强烈阴影)
- **辅助光**: 左侧45°窗边自然光模拟 (增加真实感)
- **顶部光**: 弱顶光 (消除书架顶层阴影)
- **色彩氛围**: 中性偏暖 (还原产品真实色彩)
- **特别注意**: 避免鞋面产生刺眼高光 (调整主灯角度至30°)

## 场景3：休闲落座穿搭场景

### 故事脚本：
展示日常穿搭效果，传递这款休闲鞋适配复古休闲的日常出行场景，凸显穿搭的舒适雅致与氛围感，契合复古书房的雅致调性。

**叙事功能**: 使用场景演示 + 目标用户代入  
**情绪曲线**: 认同 (这就是我的风格) → 向往 (我也想这样穿)

### 运镜技巧：
固定中景镜头，定格腿部穿搭画面，突出鞋款与穿搭的搭配效果。

**技术参数**:
- 镜头: 85mm f/1.8 (人像黄金焦段)
- 景别: 中景 (膝盖以下至脚尖)
- 机位: 固定三脚架，高度0.8m
- 构图: 三分法，鞋款位于右下交叉点
- 景深: f/2.8 (适度虚化背景，突出主体)

### 人物动作与特征：
人物身着浅卡其色中筒棉袜与复古休闲鞋，双腿自然交叠搭在沙发扶手处，姿态放松慵懒，仅露出腿部局部，未露出面部。

**模特选择标准**:
- 性别: 女 (目标用户群体匹配)
- 年龄: 25-28岁 (都市白领画像)
- 腿型: 笔直匀称 (穿鞋好看)
- 皮肤: 健康小麦色 (与暖色调协调)

**穿搭造型**:

## 场景4：球鞋材质细节特写场景

### 故事脚本：
近距离展示鞋款的做工与材质细节，凸显产品的复古质感与精良做工，强化产品的品质感与高端调性。

**叙事功能**: 工艺品质背书 + 打消质量疑虑  
**情绪曲线**: 认同 → 信任 (原来做工这么好)

### 运镜技巧：
微距推镜，从鞋头局部缓缓推进，清晰展示皮革拼接的缝线工艺与翻毛皮、牛皮的材质对比细节。

**技术参数**:
- 镜头: 100mm f/2.8 Macro (微距专用镜头)
- 放大倍率: 0.5x - 1x (等效肉眼2倍观看)
- 运动: 极缓慢推镜 (5秒移动10cm)
- 焦平面: 鞋头缝线处 (全程保持锐利)
- 景深: f/8 (微距下需要小光圈保证景深)

**微距拍摄要点**:
| 项目 | 设置 | 原因 |
|------|------|------|
| 对焦模式 | 手动对焦 (MF) | 自动对焦在微距下会拉风箱 |
| 对焦方式: | 对焦轨 + 实时取景放大 | 精确控制焦点位置 |
| 稳定性 | 三脚架 + 快门线 | 避免任何震动 |
| ISO | 100-200 (原生最低) | 保证画质纯净 |
| 快门速度 | ≥1/100s | 避免手震 (即使有三脚架) |

### 人物动作与特征：
仅展示球鞋鞋头局部，静置展示细节，无额外动作，突出材质质感。

**展示重点排序**:
1. **第一优先级** (0-2秒): 鞋头皮革拼接缝线 (体现工艺)
2. **第二优先级** (2-3.5秒): 翻毛皮与牛皮的材质对比 (体现用料)
3. **第三优先级** (3.5-5秒): 鞋孔金属扣件 (体现配件品质)

**构图细节**:
- 鞋头占据画面60%空间 (绝对主体)
- 缝线沿对角线分布 (引导视线)
- 虚化背景但保留色块 (不空洞)

### 台词/旁白：
**本场景建议静音处理** (让画面说话)

**如果必须有声音**:
```
环境音: ASMR风格的材质触摸音效
  - 01:500: 轻触皮革的"沙沙"声
  - 02:000: 指甲划过缝线的细微声响
  
音效作用: 强化"真实可触"的心理感受
音量: 极低 (20%，几乎潜意识级别)
```

**字幕方案**:
```
时间轴: 02:00 - 04:00
文字: "CRAFTSMANSHIP"
副文字: "匠心工艺 · 每一针每一线"
动画: 文字随镜头推进逐笔画显现 (书写效果)
字体: 衬线体 (Didot或Cormant Garamond)
```

### 时长与节奏：
- **持续时间**: 5秒 (微距需要更长时间消化)
- **节奏类型**: 凝重专注 (BPM 50-60, 类似心跳放慢)
- **剪辑点**: 第5秒末尾 (材质细节全部展示完毕)
- **下一场衔接**: 快速拉镜回到全景 (形成"显微镜→望远镜"的反差)

### 灯光布光：
- **主光源**: 正顶光 (垂直向下照射)
- **辅助光**: 两侧45°柔光 (消除微小凹凸的阴影)
- **轮廓光**: 后方弱轮廓光 (分离鞋头与背景)
- **关键指标**: 材质纹理清晰度 > 95% (这是本场成败的关键)

**微距布光禁忌**:
 避免直射闪光 (会产生强烈反光点)  
 避免单侧强光 (会产生无法接受的阴影)  
 避免色温不一致 (会导致材质颜色失真)

## 场景5：复古书房全景场景

### 故事脚本：
展示完整的场景空间，强化复古雅致的整体氛围，呼应产品的复古调性，为整个广告片收尾，传递出沉浸式的复古生活氛围感。

**叙事功能**: 总结升华 + 品牌世界观输出  
**情绪曲线**: 陶醉 (沉浸在这个氛围里) → 回味 (意犹未尽)

### 运镜技巧：
缓慢拉镜，从局部场景缓缓拉开，展现完整的复古书房全景，营造沉浸式的氛围。

**技术参数**:
- 镜头: 16-35mm f/4 (超广角)
- 起始焦段: 35mm (中焦，承接上一场的微距)
- 终止焦段: 16mm (超广角，展示全貌)
- 运动: 缓慢均匀拉镜 (6秒完成)
- 机位: 固定，高度1.2m (站立视角)
- 地平线: 画面下半部分1/3处 (符合构图惯例)

**拉镜的艺术**:
```
视觉效果: 从"关注细节"到"拥抱整体"
心理暗示: 从"理性审视"到"感性沉浸"
象征意义: 这不仅仅是一双鞋，而是一种生活方式
```

### 人物动作与特征：
无人物出镜，完整展示复古书房的整体空间氛围，烘托产品的适配场景。

**场景元素清单** (按重要性排序):

2. **一级支撑**: 实木书架 (占画面40%空间)

### B. 常见问题 FAQ

**Q1: 5个场景是否太多? 会不会导致节奏拖沓?**
A: 31秒5个场景平均每个6.2秒，属于快节奏剪辑。关键是每个场景的信息密度要控制好 - 场景1和4是纯氛围/细节，可以短; 场景2和3承载产品信息，可以稍长。

**Q2: 为什么不露模特面部?**
A: 这是故意的设计决策:
1. 降低观众对"这个人好不好看"的关注，聚焦产品本身
2. 增加代入感 (观众更容易想象"这双脚是我的")
3. 降低模特费用 (只拍局部价格更低)
4. 符合"低调雅致"的品牌调性

**Q3: 如果客户预算砍半怎么办?**
A: 优先级削减方案:
1.  删掉场景4 (细节特写) - 最耗时且设备要求高
2.  场景3改用静态照片代替视频 - 节省模特时间和剪辑难度
3.  保留场景1、2、5 (这三个构成完整的"引入-展示-升华"闭环)
4.  总时长压缩至20秒内 (适应更短的注意力跨度)

**Q4: 如何衡量这个视频的成功与否?**
A: 建议设定分层KPI:
- **L1 基础指标**: 播放量、完播率 (>30%为合格)、点赞率
- **L2 互动指标**: 收藏率 (代表购买意向)、评论情感分析、分享次数
- **L3 转化指标**: 点击商品详情页率、加购率、最终转化率
- **L4 品牌指标**: 搜索指数提升、品牌词关联度变化
