# 标注标准规范 (Labeling Criteria) · 注入精简版

> 本文档为 VLM 自动分类的「详细判定依据」，须与分类主 prompt 的 8 类规则**严格一致**。仅供模型判定参考，不含任何人工流程/培训内容。

## 标签体系总览（8 类，互斥，每个素材唯一一类）

| 标签 | 含义 | 关键判定 |
|------|------|----------|
| 明星穿搭 | 可识别知名明星/公众人物，以其穿搭为主体 | 必须有人物且为名人，产品非绝对主体 |
| 穿搭精选(核心) | 人物**全身**出镜，头+躯干+腿+脚均可见 | 展示整体穿搭 |
| 穿搭精选(次要) | 人物**半身**出镜，头+躯干可见、脚不可见 | 展示上身穿搭 |
| 单品展示(上脚) | **无人物头部/躯干**，仅脚部局部+商品（脚踝+鞋/鞋盒/单独摆放/膝盖以下） | 小腿肚以上不可见；绝不可归穿搭 |
| 创意静物 | 无人物，商品置于艺术置景/AI渲染/风格化场景 | 背景有设计感、非纯底 |
| 静物展示 | 无人物，商品纯色底/平铺/自然光无艺术处理 | 常规产品照 |
| 性能测试 | 视频：连续运动帧 + 科技/功能讲解（二者缺一不可） | 真实运动 + 口播/字幕讲科技点 |
| 其他 | 不属于以上任何分类 | 模糊/损坏/多品类复合/无法覆盖 |

## 详细标签定义

### 1. 明星穿搭
画面含可识别知名人物（明星/KOL/代言人），以其穿搭造型为主体，产品非视觉焦点。
- 正例：明星街拍全身穿搭（背景简洁）、代言人特写。
- 反例：明星手持运动鞋展示 → 单品展示(上脚)；明星穿羽绒服雪地行走 → 创意静物或静物展示。

### 2. 穿搭精选(核心)
人物全身出镜（头部+躯干+腿部+脚部均可见），展示完整上下装搭配，人物占比高、非局部。

### 3. 穿搭精选(次要)
人物半身出镜（头部+躯干可见、脚部/腿部不可见）；或仅下半身含大腿及以上。常见半身手持鞋展示、脚未入镜。

### 4. 单品展示(上脚)  ← 易错重点
**严格脚部特写**：画面只有「脚踝 + 穿在脚上的鞋」，且**小腿肚、膝盖、大腿、躯干、头部均不可见**（几乎看不到小腿）。纯上脚产品展示、多角度、无讲解的静态/摆拍图。
- 核心特征：只有脚部局部 + 商品本身（上脚特写/鞋盒摆拍/商品单独摆放/膝盖以下）；**绝无人物头部/躯干**。
- 易错红线：只要看到膝盖、大腿、腰、躯干任一部位，就**绝不**是单品展示(上脚)，必须归穿搭类（核心/次要）或性能测试。
- 典型场景：室内近景只拍脚踝+鞋（无运动无讲解）；脚部弯折发力摆 POSE、试穿感受文案；鞋盒摆拍、单只鞋平铺。
- 与创意静物区别：单品展示是「穿戴于脚」，创意静物是「静止艺术化摆放」；与静物展示区别：有脚部局部即上脚，无脚纯商品即静物。
- 正例："室内近景只拍到脚踝+鞋，无运动无讲解" → 单品展示(上脚)；"脚部弯折发力摆POSE、字幕'不影响做动作'" → 单品展示(上脚)。
- 反例："模特腿部穿跑鞋在跑道跑步(有运动+科技讲解)" → 性能测试；"女性上半身穿羽绒服(可见躯干)" → 穿搭精选(次要)；"产品静止桌面无人无脚" → 静物展示。

### 5. 创意静物
无人物，商品置于艺术置景/道具/光影/AI渲染/风格化设计（悬浮置景、IP联名艺术背景、节日主题道具）。纯色底无装饰 → 静物展示。

### 6. 静物展示
无人物，常规产品静物：白底/纯色简单背景、鞋盒、平铺，无艺术处理。背景允许简单纹理（木纹/水泥），但无艺术设计。

### 7. 性能测试
展示产品性能/科技/功能点，须**同时**满足：(a) 专业运动场地或明显连续运动动作（跑步/跳跃/打球）；(b) 明确科技/功能讲解（口播或字幕提中底/缓震/支撑/抓地等）。二者缺一不可。
- 图片素材（无视频）几乎不可能触发性能测试；除非画面文字明确写出科技点，否则宁归单品展示(上脚)。
- 单品展示(上脚) = 静态/摆拍脚部产品图，无运动场地、无科技讲解；即便"脚感轻盈"等试穿文案仍归单品展示(上脚)。

### 8. 其他
确实无法归入上述 7 类：模糊/损坏、多品类复合（鞋+衣+包全套搭配）、标签体系未覆盖。

## 边界案例处理指南

### 案例1：明星 + 产品共存
- 产品占比 <30% 且明星为绝对主体 → 明星穿搭。
- 明星脚部特写（仅脚踝+鞋、小腿肚以上不可见）→ 单品展示(上脚)（非穿搭）。
- 明星全身穿搭街拍 → 明星穿搭；若重点是产品且人物为模特非名人 → 按穿搭/单品判定。

### 案例2：多产品共存
- 同一品类多件（3双同款不同配色）→ 静物展示（多色展示）。
- 不同品类混搭（鞋+衣+包）→ 其他（复合型）。
- 系列产品组合（全套护肤品）→ 静物展示。

### 案例3：人 + 产品但非"使用"状态
- 人与产品明显互动（触摸/指向/悬停2cm内）→ 单品展示(上脚)（广义使用意图）。
- 人仅作为无关背景（如模糊人影、倒影）→ 忽略人，按商品判：脚部局部→单品展示(上脚)；纯商品→静物展示/创意静物。
- 人绝非穿搭类判定依据，除非头部+躯干+腿/脚可见构成穿搭。

### 案例4：创意 vs 静态模糊地带
- 明确信息传递（细节/尺寸/材质）→ 静物展示。
- 纯粹美学表达（情感/艺术）→ 创意静物。
- 两者兼有 → 取主导目的更强者。

## 常见误区与纠正

- 误区1"只要有人就是单品展示"：错。看人的角色——使用者(仅脚部)→单品展示(上脚)；背景/装饰(无头部躯干)→按商品判；绝对主体名人→明星穿搭；全身/半身出镜→穿搭精选。
- 误区2"背景复杂就是创意静物"：错。复杂背景+无艺术意图=静物展示；明显艺术设计=创意静物。
- 误区3"测试图一定是性能测试"：错。须有明确测试行为/仪器/数据；仅像实验室环境不够。
- 误区4"其他是无能表现"：错。合理使用其他是负责任的；强行归入不合适类别会污染数据。

## 红线（标签↔理由一致性·最重要）
label 字段必须与 reasoning 结论标签完全一致，矛盾即判错：
- reasoning 写"无人物/单品/仅脚踝+鞋/小腿以上不可见" → label 只能是 单品展示(上脚)，绝不可填穿搭精选(次要)/核心/其他。
- reasoning 写"全身/头躯腿脚俱全/完整人物" → label 只能是 穿搭精选(核心)；仅半身→穿搭精选(次要)；绝不可填单品展示(上脚)。
- 典型错误（严禁）：reasoning 已写"无人物/单品/上脚"，label 却填穿搭精选 → 错，应填单品展示(上脚)。
