# 商品详情页素材：全维内容理解分析模板

> **适用场景**: 电商多模态素材AI打标、内容质量评估、营销价值分析
>
> **核心目标**: 将视觉素材解构为可量化、可对比的结构化数据，支撑"得物式"精细化运营

---

## 模块一：场景时空与视觉策略（Scene & Atmosphere）

**维度定义**: 素材的"吸睛力"（Interestingness）与调性，对应得物用户对"第一眼审美"的追求 [1, 2]

### 1.1 场景心智脚本

**字段说明**: 定义场景类型与光影氛围

```
字段名: scene_type
类型: 枚举 + 自由文本
可选值:
  - 潮流街头 (Streetwear)
  - 极简室内 (Minimalist Interior)
  - 鉴别实验室 (Authentication Lab)
  - 激光蓝开箱空间 (Unboxing Space)
  - 复古书房 (Vintage Study)
  - 自然户外 (Outdoor Nature)
  - 工业风工作室 (Industrial Studio)
  - 其他: _______________
```

**填写示例**:
```yaml
scene_type: "复古书房"
lighting_style: "45°侧逆光营造皮革颗粒感，暖色调2700K模拟黄昏氛围"
atmosphere_keywords: ["雅致", "低调", "文艺", "沉浸式"]
visual_hook: "书堆+球鞋的组合制造'知识型潮流'反差感"
```

### 1.2 构图与镜头语言

**字段说明**: 分析画面构图的专业性与叙事效率

```
字段名: composition_analysis
子字段:
  - shot_type: [全景/中景/特写/微距/俯拍/仰拍]
  - rule_of_thirds: [符合/偏离] (三分法应用)
  - leading_lines: [描述引导线, 如: 书架线条指向鞋款]
  - depth_of_field: [浅景深(f/1.8)/深景深(f/8)/动态变焦]
  - color_palette: [主色调+辅助色, 如: #8B7355棕+米白]
  - visual_weight_balance: [左重右轻/对称/黄金分割点]
```

**质量评分标准**:
| 维度 | 优秀 (5分) | 良好 (3-4分) | 待优化 (1-2分) |
|------|-----------|-------------|---------------|
| 构图专业性 | 符合商业摄影标准 | 基本平衡但有改进空间 | 主体不突出或杂乱 |
| 光影运用 | 有明确情绪导向 | 光线充足但无特色 | 过曝/欠曝/阴影过重 |
| 色彩和谐 | 符合品牌调性 | 无明显冲突 | 色彩混乱或失真 |

## 模块二：人物姿态与人机交互（Character Pose & Interaction）

**维度定义**: 深度解构"生活方式投影"，将姿态翻译为模特与商品之间的"功能性对话" [1, 4]

### 2.1 静态身姿表现

```
字段名: static_pose_analysis
子字段:
  - body_language: [放松/紧张/动感/优雅/随意]
  - product_integration: [自然融合/刻意展示/被遮挡]
  - posture_narrative: [描述姿态传递的生活方式暗示]
  - visibility_score: [0-100] (商品展示完整度)
```

**填写示例**:
```yaml
static_pose_analysis:
  body_language: "放松慵懒"
  product_integration: "双腿交搭在沙发扶手，鞋款成为画面视觉重心"
  posture_narrative: "传递'阅读时光中的舒适陪伴'场景，暗示全天候穿着舒适性"
  visibility_score: 85
```

### 2.2 交互动作特征

**重点捕捉**: 人体与物品的触碰细节 → 直接对应"体验优化"标签 [3, 6]

```
字段名: interaction_details
类型: 数组
每个元素包含:
  - action_type: [按压/划过/转动/穿戴/脱卸/对比]
  - body_part: [指腹/手掌/足尖/全身]
  - product_part: [鞋底/面料/鞋带/整体]
  - function_demostrated: [回弹性/防水性/抓地力/透气性/包裹性]
  - micro_expression: [细节特写描述]
```

**典型交互动作库**:

| 动作 | 对应卖点 | 视觉冲击力 | 实现难度 |
|------|---------|-----------|---------|
| 指腹按压鞋底 | Zoom气垫回弹 |  | 低 |
| 手指划过面料 | 防泼水科技 |  | 低 |
| 足尖转动展示 | 抓地性能 |  | 中 |
| 弯折鞋身测试 | 柔韧性 |  | 中 |
| 穿戴过程记录 | 包裹性/便捷性 |  | 高 |

### 2.3 动态空间感知

**评估维度**: 商品在真实运动场景下的贴合度与稳定性 [3, 6]

```
字段名: dynamic_performance
子字段:
  - motion_type: [行走/奔跑/跳跃/蹲起/转向]
  - stability_visualization: [如何通过画面展示稳定性]
  - scene_authenticity: [场景真实性评分 1-10]
  - motion_blur_usage: [有/无] (动态模糊增强速度感)
```

**运动场景推荐矩阵**:

| 商品类型 | 推荐动作 | 场景设置 | 核心展示点 |
|---------|---------|---------|-----------|
| 跑鞋 | 慢跑/急停 | 跑道/健身房 | 缓震、抓地、透气 |
| 篮球鞋 | 变向跳跃 | 球场 | 支撑性、防滑 |
| 休闲鞋 | 行走/站立 | 街道/咖啡厅 | 舒适、百搭 |
| 户外鞋 | 攀登/涉水 | 山野/溪流 | 防水、耐磨 |

## 模块三：物品呈现与材质表征（Product Presentation）

**维度定义**: 聚焦"品质感"与"原创力"，为标品与非标品制定差异化叙事 [3]

### 3.1 核心卖点脚本

**聚焦**: 物品最吸睛的部分 [3, 7]

```
字段名: core_selling_points
类型: 数组
每个元素包含:
  - feature_name: [卖点名称]
  - visual_location: [在画面的位置描述]
  - craftsmanship_detail: [工艺细节描述]
  - brand_story_connection: [品牌故事关联]
  - uniqueness_score: [1-10] (独特性评分)
```

**典型卖点识别库**:

| 卖点类别 | 视觉特征 | 文案话术示例 |
|---------|---------|------------|
| 联名元素 | Logo刺绣/特殊配色 | "XX联名限定，全球仅XXX双" |
| 材质创新 | 特种面料/金属光泽 | "航天级材料，自清洁涂层" |
| 工艺细节 | 双层涂层/手工缝线 | "XX道工序，XX小时打造" |
| 限量属性 | 编号铭牌/特殊包装 | "第XX号/限量XXX双" |
| 科技功能 | 气垫可视/透气网面 | "搭载XX科技，提升XX%性能" |

### 3.2 材质微观叙事

**关键**: 支撑"质量保障"标签的证据链 [3, 6]

```
字段名: material_micro_narrative
子字段:
  - primary_material: [主材质名称]
  - tactile_description: [触感文字描述]
  - texture_visualization: [材质纹理的可视化程度]
  - quality_indicators: [质量指标数组]
    - 示例: ["缝线均匀度", "皮革折皱自然度", "翻毛皮绒密度"]
  - comparison_with_alternatives: [与竞品的材质差异]
```

**材质描述词汇库**:

| 材质 | 触感关键词 | 视觉特征 | 质量信号 |
|------|-----------|---------|---------|
| 翻毛皮 | 细密绒感、温润 | 绒毛均匀、无脱落 | 高端、保暖 |
| 碳纤维 | 冰凉、硬朗 | 编织纹路、光泽变化 | 科技、轻量化 |
| 头层皮革 | 光滑、柔韧 | 天然折皱、毛孔可见 | 奢华、耐用 |
| 飞织网面 | 轻薄、透气 | 编织纹理、孔洞均匀 | 运动、现代 |
| 橡胶底 | 坚实、弹性 | 纹路清晰、无气泡 | 耐磨、防滑 |

### 3.3 标准化鉴别视角

**目的**: 支撑"先鉴别，后发货"心智 [8, 1]

```
字段名: authentication_elements
类型: 数组
每个元素包含:
  - element_type: [防伪标识/鉴别证书/走线/Logo/包装]
  - visibility_level: [清晰可见/部分显示/未展示]
  - authenticity_signal: [真品特征描述]
  - consumer_reassurance: [给消费者的信心暗示]
```

**必查鉴别点清单**:

- [ ] 防伪标/二维码位置与清晰度
- [ ] 品牌Logo的字体、间距、颜色准确性
- [ ] 鞋标信息完整性（尺码、产地、货号）
- [ ] 中底走线密度与均匀度（通常9-11针/英寸）
- [ ] 鞋垫印刷质量与材质
- [ ] 包装盒序列号与鞋身一致性
- [ ] 附件齐全度（备用鞋袋、说明书、卡片）

## 模块四：人物讲解与语义逻辑（Narration & Logic）

**维度定义**: 解构讲解词的"信息量"与"交流感"，评估其种草催化能力 [3, 2]

### 4.1 讲解词结构分解

####  3秒钩子（Hook）

**目标**: 开篇即抓住注意力 [9, 2]

```
字段名: hook_analysis
子字段:
  - hook_type: [痛点打击/利益承诺/好奇心激发/权威背书/稀缺性]
  - hook_content: [实际钩子文本]
  - emotional_trigger: [触发的情绪: 焦虑/渴望/好奇/认同]
  - effectiveness_prediction: [高/中/低] (预估转化效果)
```

**高效钩子公式库**:

| 类型 | 公式 | 示例 |
|------|-----|------|
| 痛点打击 | "拒绝[负面状态]" | "拒绝臃肿，冬季也要轻盈" |
| 利益承诺 | "[数字]+[好处]" | "3秒升温，零下20°也不怕" |
| 好奇心激发 | "为什么+[反常识]" | "为什么这双鞋能穿10年？" |
| 权威背书 | "[名人/机构]+同款" | "权志龙上脚，全网断货" |
| 稀缺性 | "限量+紧迫感" | "最后200双，售完无补" |

####  核心卖点解析

**要求**: 口语化表达技术特性 [3]

```
字段名: selling_point_explanation
子字段:
  - technical_term: [专业术语]
  - colloquial_translation: [口语化翻译]
  - demonstration_method: [证明方式: 数据/对比/体验/专家证言]
  - memory_hook: [记忆锚点, 方便用户复述给朋友]
```

**专业→口语翻译对照表**:

| 专业术语 | 口语化表达 | 记忆锚点 |
|---------|-----------|---------|
| Phylon中底 | "踩屎感" | "像踩在云朵上" |
| 3M反光材料 | "夜间发光" | "晚上走路像自带灯光" |
| Gore-Tex面料 | "防水透气" | "下雨天也不闷脚" |
| Carbon Fiber板 | "抗扭" | "急停不崴脚" |
| Boost缓震 | "回弹" | "每一步都在给你助力" |

####  场景内化引导

**目标**: 让用户想象自己使用产品的场景

```
字段名: scenario_internalization
子字段:
  - target_scenario: [目标使用场景]
  - user_persona: [目标用户画像]
  - imagination_trigger: [想象力触发语句]
  - lifestyle_association: [生活方式联想]
```

**示例**:
```yaml
target_scenario: "周末城市漫步"
user_persona: "25-30岁都市白领，注重生活品质"
imagination_trigger: "想象一下，周六下午你穿着它..."
lifestyle_association: "从咖啡馆到画廊，一双鞋搞定全天穿搭"
```

####  情感表达与交流感

**评估维度**: 讲解者的语气态度与互动能力 [2, 5]

```
字段名: emotional_engagement
子字段:
  - tone: [专业测评/朋友推荐/热情种草/冷静分析]
  - attitude: [亲和/高冷/幽默/真诚]
  - interaction_commands: [互动指令数组]
    - 示例: ["大家看这里", "弹幕告诉我", "猜猜多少钱"]
  - trust_building_elements: [信任建立要素]
    - 示例: [实测数据展示, 缺点坦诚承认, 使用时长证明]
  - parasocial_feeling: [准社会交往感强度 1-10]
```

**语气风格对照**:

| 风格 | 适用场景 | 语言特征 | 适合的商品类型 |
|------|---------|---------|--------------|
| 专业测评 | 科技产品 | 数据密集、客观理性 | 功能性跑鞋、装备 |
| 朋友推荐 | 日常消费品 | 口语化、亲切 | 休闲服饰、生活用品 |
| 热情种草 | 新品首发 | 感叹词多、节奏快 | 限量联名、潮牌 |
| 冷静分析 | 高价商品 | 逻辑清晰、优缺点并述 | 奢侈品、投资级藏品 |

## 综合评估输出

###  内容质量评分卡

```
字段名: overall_quality_score
计算方式: 加权平均各模块得分

权重配置:
  - 模块一(场景视觉): 25%
  - 模块二(人物交互): 25%
  - 模块三(物品呈现): 30%
  - 模块四(讲解逻辑): 20%

总分范围: 0-100分
```

###  自动标签生成建议

基于以上分析，自动推荐的标签池:

**一级标签（品类）**:
- 单品展示 / 穿搭精选 / 场景化叙事 / 鉴别科普 / 开箱测评

**二级标签（风格）**:
- 极简主义 / 复古雅致 / 潮流街头 / 运动机能 / 奢华质感 / 亲民日常

**三级标签（功能）**:
- 材质展示 / 工艺细节 / 上脚效果 / 场景搭配 / 互动体验 / 故事叙述

**四级标签（转化意向）**:
- 强种草 (80-100分) / 中种草 (60-79分) / 弱种草 (40-59分) / 纯展示 (0-39分)

###  优化建议生成器

```
输入: 当前各项得分
输出: 具体可执行的优化建议

示例:
当前得分:
  - 场景视觉: 72/100 (光影平淡)
  - 人物交互: 65/100 (缺少互动)

建议:
  1. 【场景】增加侧逆光角度，突出材质纹理 (+8分预期)
  2. 【交互】添加"手指按压鞋底"动作展示回弹 (+10分预期)
  3. 【讲解】开头改为"拒绝臃肿"痛点钩子 (+5分预期)

综合提升潜力: +23分
```

## 使用指南

### 适用文件类型

 **支持格式**:
- 商品主图（1-9张）
- 详情页长图
- 短视频（15s-3min）
- 直播切片
- UGC买家秀

 **不适用于**:
- 纯文字描述
- Logo/图标类素材
- 抽象艺术图

### AI分析师提示词（Prompt）模板

```
你是一位资深电商内容策略师，拥有10年得物/小红书平台运营经验。
请按照以下4个模块对提供的素材进行全维分析：

【输入】{素材图片/视频帧 + 商品基本信息}

【输出要求】
1. 严格遵循上述4模块16子字段的JSON格式
2. 每个定性字段必须提供具体证据引用（如"第3秒画面左下角"）
3. 量化评分需给出评分理由（为何给4分而非5分）
4. 标签推荐需结合平台热点趋势（如当前"老钱风""多巴胺穿搭"）
5. 优化建议必须可执行、可量化、可在24小时内落地

【特别注意】
- 保持客观性，避免过度美化
- 识别潜在的合规风险（如夸大宣传、侵权元素）
- 对于模糊不清的区域，标注"需人工复核"
```
