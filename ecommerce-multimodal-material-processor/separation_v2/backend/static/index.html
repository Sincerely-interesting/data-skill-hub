电商多模态打标网关

服务端打标 · 密钥/提示词/引擎不出服务端

本服务持有模型密钥，执行自研打标引擎；客户侧仅持薄壳（纯接口层）， 通过凭证调用以下接口：

  • POST /api/v1/validate — 凭证鉴权与配额查询
  • POST /api/v1/upload — 上传素材（服务端强制类型/大小限制）
  • POST /api/v1/label — 服务端执行单单元打标
  • POST /api/v1/batch — 服务端执行批量打标（配额闸门）
  • POST /api/v1/report — 使用回执

✓ 打标在计算发生在服务端，客户薄壳不含任何 VLM 调用 / 提示词 / 引擎代码。
